### Updates

There is a one-command update script at `/home/alex/update-nextcloud.sh`:

```bash
# Preview what it will do (no changes)
/home/alex/update-nextcloud.sh --dry-run

# Run the real update: pulls images, backs up, upgrades, repairs, checks integrity
/home/alex/update-nextcloud.sh

# Update Nextcloud and the EuroOffice app from a downloaded archive
/home/alex/update-nextcloud.sh --eurooffice-archive /path/to/eurooffice-release.tar.gz
```

The script backs up the Nextcloud data directory and the MariaDB database before making changes. It is safe to run when the stack is healthy.

> **Note on version lag:** Nextcloud may advertise a newer release (e.g. `33.0.6`) before the Docker image is published. The script pulls `nextcloud:stable-apache`; if no newer image exists yet, the container stays on the previous version until Docker Hub publishes the update.

**EuroOffice app update note:** The EuroOffice app in `custom_apps/eurooffice` is side-loaded and will **not** auto-update via `occ app:update --all`. When a new release is available, use the `--eurooffice-archive` option above, or manually replace `custom_apps/eurooffice` and run `occ upgrade`.

## Troubleshooting

### Nextcloud

**Can't access Nextcloud:**
1. Verify container is running: `docker ps | grep nube-nextcloud`
2. Check port `8081` is available: `ss -tlnp | grep 8081`
3. Review logs: `docker logs nube-nextcloud`

**Slow Performance:**
1. Verify Redis is running: `docker ps | grep nube-redis`
2. Check Redis is configured for locking/cache in Nextcloud
3. Monitor MariaDB: `docker exec nube-db mariadb -u nextcloud -p -e "SELECT version();"`

### EuroOffice

**"Download failed" when opening a document:**
- Confirm `nube-eurooffice` can reach `http://nube-nextcloud/` inside the Docker network.
- Verify Pangolin is **not** stripping the `Authorization` header.
- Check that `StorageUrl` is `http://nube-nextcloud/`.

**"Nextcloud Office cannot be reached":**
- Test the health endpoint: `curl https://eurooffice.nube.bentomo.es/healthcheck`
- Ensure the `DocumentServerUrl` is `https://eurooffice.nube.bentomo.es/`.
- Check that the document server example service is running inside the `nube-eurooffice` container.

**App UI says "Nextcloud Office":**
- This is the expected rebrand of the EuroOffice app; it is **not** Collabora. The `richdocuments` app is intentionally absent.

## Security Considerations

1. **HTTPS only:** Nextcloud and EuroOffice are served over HTTPS via Pangolin; internal HTTP on ports `8081`/`8082` is trusted behind the proxy.
2. **Host ports:** Only expose `8081` and `8082` to the reverse proxy or internal network; do not bind them to `0.0.0.0` on a public interface.
3. **Secrets:** All credentials are stored in `secrets/*.txt` and are never committed. Run [setup-secrets.sh](../docker-compose/ubuntu-server-2/nextcloud-eurooffice/setup-secrets.sh) to generate them.
4. **Trusted proxies:** Broad private ranges are configured; tighten to your actual reverse-proxy subnet if possible.
5. **HSTS:** The `hsts.conf` header instructs browsers to use HTTPS for the whole `bentomo.es` tree for two years.
6. **Crafty:** Use HTTPS (`8443`) for the web UI.
7. **Dockhand:** Contains database credentials — secure the `.env` file.
8. **Portainer:** Uses its own HTTPS (`9443`) — change the default password on first login.
